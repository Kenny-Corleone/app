# LEGO Plugin System

Папка содержит расширяемые модули (плагины) SOMA AI. Каждый плагин реализует интерфейс IAgentPlugin из core.

## Структура

Каждый плагин должен:
- Реализовывать интерфейс `com.soma.plugin.api.IAgentPlugin`
- Иметь уникальное имя
- Правильно определять совместимость с запросами через метод `canHandle()`
- Обрабатывать запросы асинхронно через метод `handle()`

## Примеры плагинов

- `llama-plugin` - Плагин для работы с LLaMA моделями
- `speech-plugin` - Плагин для обработки речи
- `autofix-plugin` - Плагин для автоматического исправления кода
